# 🛒 Ecommerce App

A modern full-stack Ecommerce web application with essential shopping features and automated email notifications.  
This project is designed to demonstrate scalable architecture, clean UI/UX, and practical business logic.

---

## ✨ Features

- 🔐 **User Authentication** – Signup, login, and secure session management  
- 📦 **Product Management** – Browse products with categories, details, and search  
- 🛍️ **Shopping Cart** – Add, update, and remove items with real-time cart count updates  
- 💳 **Checkout System** – Place orders with smooth payment flow  
- 📧 **Email Notifications** –  
  - Order invoice sent to user’s email upon successful order  
  - Password reset link via email  
  - Registration confirmation email  
- 📜 **Admin Dashboard** – Manage products, orders, and users  
- 📱 **Responsive Design** – Optimized for desktop and mobile devices  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Blade (Laravel Views)  
- **Backend:** Laravel (PHP), REST APIs  
- **Database:** MySQL  
- **Email Service:** SMTP integration for automated invoices & notifications  
- **Version Control:** Git & GitHub
